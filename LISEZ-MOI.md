# Portfolio de Nathan Pluchard — mise en ligne

## Ce qu'il y a dans le dossier
- `index.html` : le site en français (page d'accueil)
- `en/index.html` : le site en anglais
- `cv-nathan-pluchard.pdf` et `cv-nathan-pluchard-en.pdf` : tes CV (téléchargeables depuis le site)
- `css/`, `js/`, `assets/` : le style, le petit script, ta photo et l'image d'aperçu
- `sitemap.xml`, `robots.txt` : ce qui aide Google à trouver et lire ton site

## Mettre le site en ligne gratuitement (GitHub Pages)
1. Sur GitHub, crée un dépôt **public** nommé exactement `NathanPluchard.github.io`.
2. Envoie-y tout le contenu de ce dossier (le fichier `index.html` doit être à la racine du dépôt).
3. Dans le dépôt : Settings → Pages → Branch `main` → Save.
4. Après une minute, le site est sur `https://nathanpluchard.github.io/`.

## Pour que Google te trouve quand on tape ton nom
1. Va sur https://search.google.com/search-console et ajoute ton site.
2. Envoie le sitemap : `https://nathanpluchard.github.io/sitemap.xml`.
3. Mets l'adresse du site dans ta bio GitHub et sur ton profil LinkedIn : ces liens aident beaucoup.
4. Patience : l'indexation prend de quelques jours à quelques semaines.

## Si tu prends un nom de domaine plus tard (ex. nathan-pluchard.fr)
Remplace `https://nathanpluchard.github.io` par ta nouvelle adresse dans `index.html`, `en/index.html`, `sitemap.xml` et `robots.txt`.

## Ajouter ton projet Roblox plus tard
Dans `index.html` et `en/index.html`, remplace le bloc « Un jeu Roblox arrive bientôt » (classe `soon`) par une carte projet, sur le modèle d'OUTBREAK.
